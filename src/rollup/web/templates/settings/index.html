Network sources opt-in

LinkedIn

Manage named fromMember searches on the LinkedIn page. Session cookies stay in ~/.config/rollup/env — never in TOML.

Reddit

Manage subreddits on the Reddit page. No credentials required (public JSON/RSS). Optional OAuth lives in ~/.config/rollup/env.

RSS

Manage feeds on the RSS page. Fetch happens at digest time. There is no unread inbox.

Gmail

Read-only Gmail API ingest for people without a Thunderbird mbox tree. Labels become digest folders (Newsletters/tech → tech when the prefix is stripped). Authorise once with rollup gmail auth; the OAuth client id/secret live in ~/.config/rollup/env and the token in state_dir/gmail_token.json. Rollup only requests gmail.readonly.

Google Scholar mail enrichment

Scholar alerts already in Thunderbird. Default treats them like other item-list mail (no extra network). Detailed fetches each paper’s landing page and summarises it (HTTPS at digest time; LLM summaries still need Enable LLM summaries). PDFs are skipped; arXiv PDF links are rewritten to abstract pages.
