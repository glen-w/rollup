LinkedIn searches

Named fromMember content searches become briefing sections. GET never contacts LinkedIn; fetches happen only during a digest run.

How to add a search

Copy the URL from LinkedIn after filtering Content search by people — the address bar must contain fromMember= and ACo… ids. Session cookies go in ~/.config/rollup/env as ROLLUP_LINKEDIN_LI_AT and ROLLUP_LINKEDIN_JSESSIONID — never in TOML. Keyword-only search is not supported yet.
